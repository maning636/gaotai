## 遗留（按优先级）

1. **`appId` 中性化**（`com.maning.gaotai`）：转公开仓或首次对外公开发布时执行，
   触发条件与影响面见 ADR-0003；不能只改配置，要同步升级/覆盖安装说明。
2. **源码归档需重出**：`release/gaotai-source-0.1.0.zip` 是第二批改动之前的快照，
   不含 deps-gate、ESLint 配置、ADR-0003 与瘦身后的 README。对外交付前重新生成并重扫密钥。
3. **验收表 build/read/roundtrip 三件套**（#27）：经评估对本项目属过度工程
   （无结构化验收表数据），建议标准放宽为「有验收表才必配」；若必须保留，先定义验收表格式。
4. **打包烟测的能力边界**：CI 只证明「干净 Windows 能从源码出包」，
   装得上 / 能启动 / 四道工序跑通仍靠本机 `.tmp/` 脚本与人工验收（临时脚本不入库）。
5. **私域分发的体积与防覆盖无自动守卫**：按 ADR-0003 由本地纪律 + CHANGELOG 承担，
   出包后必须核对 `release/` 清单与体积。
