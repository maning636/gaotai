# 稿台：把一堆素材，变成一篇能发出去的公众号长文

> 一份纯文字的产品介绍。没有截图，可以直接复制到公众号、朋友圈、或者发给任何一个想聊这件事的人。

---

## 一句话

稿台是一个**跑在你自己电脑上的**公众号写作工作台。

你把素材丢进去，它分四道工序一步步把它写成稿子，**每一道都要你点头才往下走**。稿子、数据、密钥全在你自己那台机器上：没有账号，不按字收费，不联网也能写（除了调模型那一下）。

---

## 它替谁解决什么

它写给这几类人：一个人做技术公众号的、团队里负责对外表达的、每周要交几篇稿子的运营。

这些人都卡在同一件事上：**素材有一堆，但成稿没有**。

具体是这么卡的：

**一、素材不是稿子。** 仓库、聊天记录、issue、评论、一次失败的迁移、一段跟朋友的口述——这些是原料，扔给 AI 让它"写一篇"，出来的是功能清单加一段总结。**没有人在稿子里看见自己。**

**二、AI 一把梭的稿子一眼就假。** "随着 AI 技术的不断发展"、"这不仅仅是…更是…"、"值得注意的是"。手机上滑两秒就走。

**三、过程是黑盒。** 你不知道它中间改了什么、改得对不对，只能整篇读一遍重来。

**四、排版和推草稿是另外一摊事。** 写完了还要调样式、传图、转格式、粘进公众号后台。

**五、数据在别人手里。** 稿子、密钥、写作习惯，全在别人的服务器上。

稿台对的就是这五条。

---

## 它能做什么

| 能力 | 具体在做什么 | 你得到什么 |
| --- | --- | --- |
| **四道工序** | 材料解读 → 选题与方向 → 写作大纲 → 文章正文 | 每一步都有看得懂的产出，不用对着黑盒猜 |
| **签字才往下走** | 上一道工序你不点头，下一道不启动 | 不会跑到第四步才发现方向错了 |
| **大纲里先定「谁在说」** | 谁在说、凭什么知道、他的判断、读者的追问 | 全篇一个口气，读者能看见有个人在跟他说话 |
| **技能包** | 写作方法可以整体替换：内置一套、第三方一套、你自己写一套 | 方法不是焊死在产品里的 |
| **风格记忆** | 从你每次手改的差异里长出画像 | 写得越久越像你，不用每次重申"我的风格是…" |
| **排版模板** | 23 个部件自由取舍，21 套随包样式包开箱可用 | 导出的 HTML 直接贴进公众号后台就是最终排版 |
| **配图** | 图从外面来（生图工具、截图、照片），传进来插进正文 | 推草稿时图跟着走，不会推过去是空的 |
| **导入已有文章** | 把公众号里复制出来的 HTML 变成干净的 Markdown | 老稿子能接着改，不用重写 |
| **公众号闭环** | 先测通道 → 预览 → 推草稿箱 → 看阅读在看 | 通道不通会直接告诉你卡在哪 |
| **查 AI 味** | 标出模板腔、排比、翻案腔、重复 | **只报警，不替你改稿** |
| **概览** | 稿件卡在哪一步、按专题分布、最近的人工修改 | 这台机器上的创作轨迹，一眼看完 |

## 界面长什么样

### 整体

一个桌面客户端窗口。**左边是导航，右边是工作区**，没有多余的东西。

左边从上到下分三组：

- **写作**：工作台、稿件、概览
- **资产**：风格、排版、素材
- **接入**：公众号、模型

最下面是版本号和"本地运行"两个字——提醒你：它在你机器上，不在别处。

### 工作台

打开就是这一页。上面一个大标题，下面两块：**「开一篇新稿」**和**最近写的几篇**。没有仪表盘、没有统计图表——这个工具的第一件事是写，不是看报表。

### 稿件页（主要战场）

一进来先看到顶部的**工序带**：四格，横着排——

```
[1 材料解读] [2 选题与方向] [3 写作大纲] [4 文章正文]
```

每格右下角有状态：「未开始」「草稿」「已签字」。当前那道是亮的，点别的格子就切过去。**一眼看出这篇稿子走到哪了。**

下面是左右两栏：

- **左栏**：上面是这一阶段的对话记录（你和 AI 来回说的每一句都留着）；中间是输入框「丢素材，或者问一句」；再下面是当前专题的说明和**技能包勾选区**——哪个技能包这次用，你说了算，不勾就用专题默认的。
- **右栏**：这一阶段的产出，直接在框里改。下面一排按钮：**保存修改、签字确认、复制、配图提示词、插入图片、查 AI 味**。

「签字确认」是这套流程的关键按钮：点了它，这道工序的产出才算定稿，下一道才允许拿它当既定事实。**没签字的产出不会被当成定稿往下传。**

### 素材库

你传进来的所有图。点「上传图片」可以批量传，每张图有「复制引用」「复制地址」。文件名保留原样（`2026-10-24_横版_公众号知乎_承受得起_2000x1116.jpg` 这种），一眼认得出哪张是哪张。

### 排版

上面一句话讲清怎么用：**导入 → 取舍 → 固化 → 迭代**。

下面是模板库。选中一套模板后，可以逐个部件地勾——不要的不勾就不输出；勾上的还能改它的 HTML、固定文本和色值。右边是预览，用一篇示例稿把稿台会排到的元素全摆一遍，改一处立刻能看到效果。

改完存下来就是**你自己的模板**，之后每篇稿子都能选它。

### 风格

标题就一句话：**你的写作习惯，是怎么从修改记录里长出来的。**

上面是「风格来自你亲手改的地方」——你每次手改的差异都在这儿。下面是「模型实际会读到的画像」：用词、句长、口语程度、删减习惯，一条条列着，每条都能看出是从哪次修改里总结出来的。

### 公众号

一页里从上到下五块：

- **公众号接入**：填 AppID / AppSecret，点「测试连接」先验通道通不通
- **封面图**：上传一张，或者从素材库里选一张已有的
- **推草稿箱**：选一篇走完正文的稿件 → 选排版模板 → 推过去
- **已发布文章**：同步回来的列表
- **阅读数据（近 7 天）**：阅读、在看、分享

**先测后发**：没测通就不让推，错误码翻成人话——比如微信报 40164，界面直接把"该填哪个 IP"告诉你。

### 模型

一块「模型接入」：Base URL、API Key、模型名，还有思考强度。Key 加密后落盘，界面上只显示一串圆点。

### 概览

三块：**稿件卡在哪一步**（哪篇停在哪道工序）、**按专题分布**、**最近的人工修改**。

## 能达到什么效果

这些是**实测出来的**，不是形容词：

| 指标 | 实测 |
| --- | --- |
| 正文产出 | 默认篇幅下 900 字上下，**一次交出**（不是反复催出来的） |
| 正文耗时 | 快的那次 15.9 秒；慢的模型几分钟，但一定会交出正文，不会空手 |
| 大纲产出 | 120 秒量级，带推进线、说话位置、逐段分工 |
| 成稿体检 | 硬禁令能清到 0 条；只报警不自动改 |
| 排版 | 23 个部件，21 套随包样式包，导出的 HTML 可直接贴进公众号后台 |
| 推草稿 | 幂等：内容没变就不重复推，改了才更新那一份，不会草稿箱里躺两份 |
| 数据 | 全在本机。断网也能写稿（除了调模型那一下） |

还有一条**不好量化但很要紧**的：正文阶段**不给模型任何工具**，也不塞字数指令。

这两条都是被真模型教训出来的——给工具、把禁令清单塞进去，模型会先在心里逐条核对，思考额度吃光，正文一个字都交不出来。**方法给出路，禁令只给墙。**

## 适合谁

- 一个人做技术号／产品号，每周要交稿的人
- 团队里对外表达的人（技术负责人、创始人、运营）
- 已经在用 AI 写、但受不了"一眼就假"的人
- 不想把稿子和密钥交出去的人

## 不适合谁

- 想要一键出稿、从不看过程的人（这套流程的价值全在"你要看、要改、要点头"）
- 需要团队协作与云端同步的人（它是**本地**工具，这是取舍，不是没做完）
- 要一次写五万字长篇的人（它按 700–1200 字的口径做短稿）
- 不想自己准备模型 Key 的人

---

## 三步开始

1. **装上，双击打开。** 没有账号、没有注册、没有"激活码"——打开就是用。
2. **在「模型」页填上你的模型 Key。** 稿台不自带模型，也不按字收费，你用谁家就填谁家。
3. **新建一篇稿，把素材贴进去。**

想试快一点的：**「素材」页上传两张图 → 稿件页「插入图片」→ 推草稿箱**，这条路不调模型也能走通。

---

## 几句诚实的边界

- **稿台不生图。** 图是你在别的地方生成的，它负责把图收进来、插进正文、推草稿时换成微信自己的地址。
- **推公众号草稿要过 IP 白名单。** 微信只认最多 20 个精确公网 IPv4，家宽动态 IP 填了也会失效。绕不过去，得有固定出口。
- **安装包没有签名。** 别人第一次装会看到系统提示"未知发布者"，点"更多信息 → 仍要运行"就行。
- **它不替你改稿。** 体检只标出"这里像模板腔"，怎么改是你的事。

---

## 一句话收尾

它做的事其实不复杂：**把"写不出来"拆成四步，每一步都让你看见、都让你点头。**

其余的——数据在你机器上、密钥不外传、不按字收费——都是为了让这一步你敢信。
