### 3.3 push 挂死怎么办（**必读**）

本机全局配了 `http.proxy=http://127.0.0.1:7897`。**代理通不通每次都不一样**（实测两次翻转：一次代理死直连活，一次反过来）。

先探两条路，哪条通用哪条：

```powershell
# 探直连
git -c http.proxy= -c https.proxy= ls-remote origin
# 探代理
git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897 ls-remote origin
```

- 哪条 2 秒内返回就用哪条推（`git push` 同样带这两个 `-c`）。
- **只对当次命令加 `-c`**，别改全局配置（改了会影响别的项目）。
- **走 SSH 完全绕开这个代理**（SSH 不读 `http.proxy`）→ 如果 SSH key 已在 GitHub 账号上注册，优先用 SSH。

## 4. 本机开发与出包

```powershell
npm install          # 依赖
npm run dev          # 开发态 http://127.0.0.1:3060
npm test             # 366 条单测，不需要模型、不联网
npm run typecheck    # tsc --noEmit
npm run desktop:build   # → release/（安装包 + 免安装版）
```

出包注意事项：

1. **先关掉正在运行的 `稿台.exe`**，否则 portable 目标会一直等文件锁（表现是构建卡在「building target=portable … waiting for unlock」）。
2. 出包会在 `%TEMP%` 留下 `ns*.tmp`（NSIS 编译临时目录），收尾清掉。
3. **没有 Visual Studio 的机器**：`npm install` 要加 `--ignore-scripts`，然后手动跑 `node scripts/ensure-runtime-deps.mjs` 补原生模块。
4. 别在 `release/` 目录里双击安装包测东西 —— 每次出包都会覆盖那个文件，正在开的安装向导会反复弹。

## 5. 分发方案（软件怎么到用户手上）

**免费 + 私域分发**，没有服务器、没有按量计费：

```
公众号文章 → 引导加微信 → 发 exe
```

| 形态 | 文件 | 建议 |
| --- | --- | --- |
| 免安装单文件版 | `release\稿台 0.1.0.exe` | **主推**：解压即用，零安装摩擦 |
| 安装包 | `release\Gaotai-Setup-0.1.0.exe` | 需要固定安装位置的用户 |

用户侧的体验（这些是设计承诺，交付时别改坏）：

- **首次打开直接进**，没有账号、没有注册、没有激活码（桌面端用启动令牌自动换会话）
- **模型要自己带 Key**：在「模型」页填 Base URL / Key / 模型名，稿台不自带模型、不按字收费
- **数据全在用户机器上**：`%APPDATA%\gaotai`
- 未签名 → SmartScreen 会说「未知发布者」，点「更多信息 → 仍要运行」→ **推广文案里要提前说**
- 推公众号草稿要过 **IP 白名单**（微信只认最多 20 个精确公网 IPv4）——这是唯一绕不过去的坎，推广时别承诺"装完就能推"

## 7. 会踩的坑

完整 10 条在 [`file-map.md`](file-map.md) 的 §6，这里是最容易致命的几条：

1. **提示词是进程内缓存的**：改 `resources/prompts/*.md` **必须重启**才生效。
2. **正文阶段不要给模型工具**：给 `check_prose` / `read_skill_file` 会把思考额度吃光，正文一个字交不出来（真模型实测）。写作方法由服务端注入。
3. **注入方法，不要注入禁令清单**：十条硬禁令会让模型逐条核对，实测 16384 额度全进思考、正文 0 字。
4. **正文不给字数指令**：`renderLengthInstruction()` 的参数类型里根本没有 `article`。
5. **正文里的图片地址是百分号编码的**：推草稿时必须解码回文件名才找得到文件，否则图不会上传微信、稿子推出去是空的。
6. **公众号不认外链图**：导入的老文章带外链图，要先下载到本机再上传。
7. **改 `layout-template.ts` 的清洗器前先跑测试**：样式值里的 `{{变量}}` 曾被连同整条声明丢掉 → 部件悄悄没样式且不报错。
8. **出包前关掉运行中的实例**；出包后清 `%TEMP%\ns*.tmp`。
9. **Windows 上 Node 调 cmd.exe**：命令串不要额外包外层引号，要开 `windowsVerbatimArguments`。
10. **git push 挂死先探直连/代理**（§3.3），别原地重试。
